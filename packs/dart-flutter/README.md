# UniversalTools: Dart & Flutter

Official Dart and Flutter support.

A standalone UniversalTools pack. The main [UniversalTools](https://marketplace.visualstudio.com/items?itemName=universaltools.universaltools) web pack does not install it; install it on its own when you need these extensions.

**Developer:** [Otabek Sadiridinov](https://github.com/otabekoff) · [Source code](https://github.com/otabekoff/universaltools/tree/master/packs/dart-flutter) · [Report an issue](https://github.com/otabekoff/universaltools/issues)
