# UniversalTools: C/C++

C/C++ IntelliSense and debugging, CMake and Makefile projects, and the CodeLLDB debugger.

A standalone UniversalTools language pack. The main [UniversalTools](https://marketplace.visualstudio.com/items?itemName=universaltools.universaltools) web pack does not install it; install it on its own when you work in this language.

**Developer:** [Otabek Sadiridinov](https://github.com/otabekoff) · [Source code](https://github.com/otabekoff/universaltools/tree/master/packs/cpp) · [Report an issue](https://github.com/otabekoff/universaltools/issues)
