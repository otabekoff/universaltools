# UniversalTools: Quasar

Vue - Official plus IntelliSense for Quasar 2 components and Quasar CSS classes.

Part of [UniversalTools](https://marketplace.visualstudio.com/items?itemName=universaltools.universaltools), which installs this pack together with the other UniversalTools web packs. Install this one on its own if you only need these extensions.

**Developer:** [Otabek Sadiridinov](https://github.com/otabekoff) · [Source code](https://github.com/otabekoff/universaltools/tree/master/packs/quasar) · [Report an issue](https://github.com/otabekoff/universaltools/issues)
