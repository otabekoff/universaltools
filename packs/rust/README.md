# UniversalTools: Rust

rust-analyzer, the CodeLLDB debugger, Cargo.toml support and crate version hints.

Part of [UniversalTools](https://marketplace.visualstudio.com/items?itemName=universaltools.universaltools), which installs this pack together with the other UniversalTools packs. Install this one on its own if you only need these extensions.

**Developer:** [Otabek Sadiridinov](https://github.com/otabekoff) · [Source code](https://github.com/otabekoff/universaltools/tree/master/packs/rust) · [Report an issue](https://github.com/otabekoff/universaltools/issues)
