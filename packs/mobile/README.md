# UniversalTools: Mobile

React Native and Expo development tools.

A standalone UniversalTools language pack. The main [UniversalTools](https://marketplace.visualstudio.com/items?itemName=universaltools.universaltools) web pack does not install it; install it on its own when you work in this language.

**Developer:** [Otabek Sadiridinov](https://github.com/otabekoff) · [Source code](https://github.com/otabekoff/universaltools/tree/master/packs/mobile) · [Report an issue](https://github.com/otabekoff/universaltools/issues)
