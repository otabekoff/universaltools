# Recommended settings, already on

UniversalTools changes these **defaults**. Anything you set yourself still wins.

| Setting | Default from UniversalTools | What it does |
|---|---|---|
| `editor.linkedEditing` | `true` | Renaming an opening HTML tag renames its closing tag |
| `editor.guides.bracketPairs` | `"active"` | Guide lines for the bracket pair you are in |
| `[css]`, `[scss]`, `[less]` formatter | Prettier | Format stylesheets with Prettier |
| `[xml]` formatter | XML (Red Hat) | Format XML files |

Bracket pair colours and HTML/JSX tag closing are built into VS Code and already on.

To change any of these, open your settings and set your own value.
