# Welcome to UniversalTools

UniversalTools installs 14 packs. For web development:

- **Web Core:** ESLint, Prettier, Biome, GitLens, GitHub Pull Requests, Live Preview, Edge DevTools, Live Share, Vitest, Playwright, Error Lens and more
- **HTML & CSS:** Tailwind CSS, UnoCSS, PostCSS, Sass, Stylelint, CSS Peek, Auto Close Tag
- **Frameworks:** Vue, Svelte, Astro, MDX, React snippets, Slidev, Tauri
- **Quasar:** Vue plus Quasar 2 component and CSS class IntelliSense
- **Everyday Tools:** CodeSnap, Google Translate, Code Runner, Terminal Keeper, a PDF viewer, a status bar clock, a theme and file icons

For other languages, AI and DevOps:

- **Languages:** Python, C/C++, Rust, Dart & Flutter, Java & Kotlin, Mobile (React Native, Expo), Go
- **AI:** Claude Code, Codex, Google Antigravity, Gemini Code Assist, Cline, Continue, Ollama
- **DevOps & Config:** Remote SSH, PowerShell, shell script tools, nginx, Apache and systemd files, log files, CSV

Each pack is also on the Marketplace on its own, if you only need part of the set.
