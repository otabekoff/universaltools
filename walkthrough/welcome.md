# Welcome to UniversalTools

UniversalTools installs five packs of web-development extensions:

- **Web Core:** ESLint, Prettier, Biome, GitLens, GitHub Pull Requests, Live Preview, Vitest, Playwright, Error Lens and more
- **HTML & CSS:** Tailwind CSS, UnoCSS, PostCSS, Sass, Stylelint, CSS Peek, Auto Close Tag
- **Frameworks:** Vue, Svelte, Astro, MDX, React snippets
- **Quasar:** Vue plus Quasar 2 component and CSS class IntelliSense
- **Everyday Tools:** CodeSnap, Google Translate, a status bar clock, a theme and file icons

Each pack is also on the Marketplace on its own, if you only need part of the set.
