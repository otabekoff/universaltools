# Welcome to UniversalTools

UniversalTools installs a curated set of extensions for web development:

- **Frameworks:** Vue, Svelte, Astro, MDX, React snippets
- **Lint and format:** ESLint, Prettier, Biome, Oxc, Stylelint, EditorConfig
- **CSS:** Tailwind CSS, UnoCSS, PostCSS, Sass, CSS Peek
- **Preview:** Live Preview, Live Server, Open in Browser
- **Testing:** Vitest, Playwright
- **Git and GitHub:** GitLens, Pull Requests, GitHub Actions
- **Everyday tools:** Error Lens, Spell Checker, Better Todo Tree, CodeSnap, Google Translate and more
